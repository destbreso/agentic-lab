# Challenge: Sorting Module

## Objective

Implement a TypeScript sorting module (`sort.ts`) that provides multiple sorting
algorithms. The module must be correct, performant, well-typed, and handle edge
cases gracefully.

## Requirements

Both agents start with the same stub file. The agent that produces the best
overall implementation wins.

## Rounds

### Round 1: Core Algorithms
Implement at least 3 sorting algorithms with a unified API.

### Round 2: Optimization
Improve performance. The Arbiter will benchmark both solutions with large arrays.

### Round 3: Edge Cases & Polish
Handle all edge cases, add type generics, clean up code quality.
