# Agent Spec examples the lab did not write

Copied unchanged from Oracle's repository `oracle/agent-spec` at commit `9beda2b`, folder `docs/pyagentspec/source/agentspec_config_examples/`, as test fixtures for importing a document written elsewhere:

- `howto_flow_with_conditional_branches.yaml` and `.json`: a flow that writes code, reviews it and goes back to writing while the review says no. Its way back has no limit. The two files are Oracle's own twins; they differ only in their generated ids.
- `howto_agents.yaml`: a standalone agent with tools.
