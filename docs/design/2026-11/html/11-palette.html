Rules
  • Colour means the state of a run or the one primary action. Nothing else gets a hue: not a role, a link, a chart series or a tag.
  • Roles are told apart by icon, name and position. A role drawn in green is running, not "the green role".
  • Provenance is a glyph and a type style, so it survives a terminal with no colour and a reader who can't tell hues apart.
  • Structure is lightness only: the same green-grey at four steps.
  • Every colour is a token, defined once: globals.css in the web, a meaning table in the CLI. A hue class in a component fails a check.
  • Two departures from destbreso.com: text is a near-neutral ink rather than terminal green, so that green can mean running; and the site's amber becomes "waiting for you" instead of a decoration.
